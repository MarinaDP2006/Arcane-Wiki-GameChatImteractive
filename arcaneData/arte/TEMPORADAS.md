# Imágenes separadas por temporadas

El juego ya impide mostrar imágenes de T1 como si fueran de T2. Si falta una imagen específica de T2, utiliza el dibujo de reserva, **no la imagen de T1**.

La colección existente se conserva intacta para no borrar las imágenes que subiste. La selección de imágenes auténticas de internet aún requiere descargar, verificar fotograma/temporada y comprobar que los lugares no tengan personajes.

Carpetas esperadas para imágenes nuevas: `src/img/arte/lugares/s1/`, `src/img/arte/lugares/s2/`, `src/img/arte/personajes/s1/`, `src/img/arte/personajes/s2/`, `src/img/arte/caras/s1/`, `src/img/arte/caras/s2/`. El archivo `FUENTES-POR-TEMPORADA.json` recoge galerías para cotejar las imágenes.
