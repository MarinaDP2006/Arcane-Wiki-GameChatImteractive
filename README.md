# Arcane-Wiki-GameChatImteractive
En este repositorio es una wikipedia de personajes, mundo, criaturas, lugares de Arcane. Además, hay un juego chat+audio de personajes de la serie, donde tendrás que crear tú personaje e ir interactuando con los planes. eligiendo si ser de Zaun o Piltover previamente para ir desbloqueando personajes e historia. Tendrás que decidir que hacer.
